# BlockTodo

[English](./README.md) | **简体中文**

> 面向思源笔记的**块原生**待办插件。两种数据空间、三种视图形态、四个状态列，数据始终是笔记里真实的任务列表块。

## 两种数据空间

| 空间 | 说明 |
|---|---|
| **SiYuan 任务** | 你在任何文档里手写的 `- [ ]` 任务列表块。插件自动汇总，改一处两边同步。 |
| **独立空间** | 一棵**不限层级**的任务树，存放在插件自动创建的《BlockTodo 任务树》文档里，不干扰日常笔记。 |

两边都是思源里真实的块：卸载插件、删掉插件目录，任务一个都不会丢。扩展字段（优先级、状态、截止日期、重复、分类、备注）保存在块属性里，不污染正文 markdown。

## 三种视图形态

| 视图 | 用途 |
|---|---|
| **列表** | 跨文档平铺，按日期 / 优先级 / 分类 / 文档分组；虚拟滚动，上万条也不卡。 |
| **树形** | 只看层级：任意节点可继续加子任务，节点可折叠；把任务拖到另一个节点上即成为它的子任务。 |
| **看板** | 按状态分四列（待办 / 执行中 / 已完成 / 已归档），把卡片拖到别的列就改了状态。 |

### 界面分区

| 位置 | 内容 |
|---|---|
| 左侧边栏 | **数据范围**：全部任务 / SiYuan 任务 / 独立空间；底部为设置入口 |
| 内容区顶栏 | 搜索框、分组与排序，**右上角**为视图切换（列表 / 树形 / 看板） |
| 搜索栏下方 | **时间**（今天 / 近七天 / 全部 / 回收站）与**状态**筛选；点 `≡` 展开优先级 / 截止 / 分类等高级条件 |

三组条件自由组合：范围 × 视图形态 × 时间与筛选。

## 状态模型

状态由「块勾选态 + 属性」共同决定，既能和笔记原生行为兼容，又能表达更多阶段：

| 状态 | 存储方式 |
|---|---|
| 待办 | `[ ]` 且无状态属性 |
| 执行中 | `[ ]` + `custom-bt-status="doing"` |
| 已完成 | `[x]`（就是笔记里的勾选） |
| 已归档 | `[ ]` + `custom-bt-status="archived"` |

所以在思源里手动勾掉一个任务，插件里立刻变成「已完成」；反过来在看板里拖到「已完成」，对应的块也会被勾上。

## 高级搜索

工具栏的 `≡` 打开筛选面板，可以叠加使用：

- 按**状态**多选（每项带数量角标）
- 按**优先级**多选
- 按**截止**：已逾期 / 今天到期 / 本周内 / 无日期
- 按**分类包含**（子串匹配）
- 顶部搜索框按**标题 / 备注 / 分类 / 文档路径**实时过滤

## 交互

| 操作 | 方式 |
|---|---|
| 完成 / 重开 | 点左侧圆圈，或选中后按 `空格` |
| 编辑标题 | 双击，或选中后按 `Enter` |
| 切换优先级 | 点 P0-P3 色签循环，或在详情面板直接选 |
| 切换状态 | 看板里拖卡片换列，或详情面板点状态胶囊 |
| 加子任务 | 行右侧 `+`；树形视图里拖节点到目标节点上 |
| 折叠 / 展开 | 行首箭头 |
| 缩进 / 反缩进 | `Tab` / `Shift+Tab`（真实改变块层级） |
| 上下移动选择 | `↑` `↓` |
| 新建 | `N` |
| 移入回收站 | `Delete` |
| 撤销 / 重做 | `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` |
| 多选 | `Ctrl/Cmd+点击` |
| 拖拽排序 | 排序方式切到「手动」后拖动任务行 |

完成父任务会级联完成全部子孙；重新勾开任意子任务，父任务也会恢复为未完成。

## 性能

| 做法 | 说明 |
|---|---|
| 单次查询带 `ial` | 一条 SQL 同时取回块内容与全部属性，避免每条任务一次属性请求（N+1）；老内核自动降级为并发受限的惰性加载 |
| 事务增量同步 | 订阅内核 `transactions`，只对受影响的块重新查一次，**没有定时器、没有全量快照比对** |
| 窗口化渲染 | 超长列表只渲染视口内的行 + 上下缓冲区，滚动用 `requestAnimationFrame` 节流 |
| 共享派生缓存 | 子任务统计、分组、排序各自只算一次，所有行/卡片共享同一份结果 |
| 乐观更新 + 回滚 | 先改本地再落盘，失败自动回滚并提示，UI 不阻塞 |
| 写入去重 | 属性写入只传真正变化的键；配置写入做 400ms 合并落盘 |
| 零运行时依赖 | 除 Vue 外不引入任何第三方库，产物约 130KB |

## 数据结构

| 块属性 | 含义 |
|---|---|
| `custom-bt-p` | 优先级，值 `P0`…`P2`；不存在表示 P3 |
| `custom-bt-status` | `doing` / `archived`；不存在表示待办 |
| `custom-bt-due` | 截止日期，`YYYY-MM-DD` |
| `custom-bt-repeat` | 重复规则，`1d` `3d` `1w` `2w` `1m` `3m` `1y` |
| `custom-bt-cat` | 分类名 |
| `custom-bt-note` | 备注文本 |
| `custom-bt-sort` | 手动排序权重 |
| `custom-bt-trash` | 存在即代表在回收站 |

删除 ≠ 丢失：默认只做软删除（写 `custom-bt-trash`），只有在回收站里点「永久删除」才会真的删掉笔记里的块。

## 开发

```bash
npm install
npm run assets       # 生成 icon.png / preview.png
npm run typecheck    # vue-tsc 类型检查
npm run build        # 输出 dist/ 与 package.zip
```

本地联调（推荐，改动自动重载）：

```bash
# .env.local
VITE_SIYUAN_WORKSPACE_PATH=D:/siyuan_data
npm run dev          # 构建产物直接写入 工作空间/data/plugins/siyuan-plugin-blocktodo/
```

然后在思源里禁用再启用一次插件即可。

> 注意：不要把源码目录直接放在 `data/plugins/` 下，它会被同步，卸载插件时整个目录会被删除。

## 上架集市

> 澄清：这里的 PR 是**给思源官方集市索引仓库登记你自己的仓库**，不是给某个插件作者提代码。
> 你完全自建，不需要 Fork 别人的插件，也不需要通知任何原作者。
> 若只想自己用、不想进集市，可以跳过本节与这个 PR，直接在思源里
> `设置 → 集市 → 已下载 → 插件 → 手动安装` 选择本地 `package.zip` 即可。

1. 把 `plugin.json` 里的 `author`、`url` 改成你自己的 GitHub 信息（`name` 必须与仓库名一致）。
2. `npm run release` 通过后在 GitHub 新建 Release：Tag = 插件版本号（如 `0.2.0`），并附上 `package.zip`。
3. Fork [siyuan-note/bazaar](https://github.com/siyuan-note/bazaar)，在 `plugins.txt` 末尾加一行 `你的用户名/siyuan-plugin-blocktodo`，提 PR 到 `main`。
4. 一个 PR 只加一个包；CI 会自动校验 release、`package.zip` 与清单字段。合并后几分钟内集市索引更新（需重启一次思源）。

后续发新版无需再提 PR，索引每 1–3 小时自动更新。
