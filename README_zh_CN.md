# SYTodos

**SY 待办** · 思源笔记里的待办管理插件｜[English](./README.md)

![界面预览](preview.png)

把散落在各个文档里的 `- [ ]` 待办收拢到一处，用列表、树形、看板三种方式管理。所有数据都是你笔记里真实存在的块，插件只是给它们换了个更好用的界面。

- **不搬家**：待办还在原来的笔记里，插件不会把数据藏进私有数据库。
- **不上传**：纯本地运行，不联网、不采集，不需要账号。
- **不丢数据**：卸载插件，笔记里一条待办都不会少。
- **不卡顿**：几千条待办照样流畅，列表只渲染你看得见的部分。

## 安装

**方式一：从集市安装**

打开思源笔记 → `设置` → `集市` → `插件` → 搜索「**SY 待办**」→ 点击安装。

**方式二：手动安装**

1. 下载插件包 `package.zip`；
2. 在思源里打开 `设置` → `集市` → `已下载` → `插件`；
3. 点右上角的手动安装按钮，选择 `package.zip`；
4. 安装完成后**重启一次思源**。

**启用**

安装后如果顶栏没有出现勾选图标，去 `设置` → `集市` → `已下载` → `插件`，确认「SY 待办」的开关是打开的。

支持 Windows、macOS、Linux、Docker，以及手机端和浏览器端；需要思源笔记 **3.0.0 或更高版本**。

## 五分钟上手

1. **打开**：点击顶栏的 ✓ 图标，或按 `Ctrl+P` 搜索「打开 SY 待办」。
2. **看已有待办**：左侧默认停在「SiYuan 空间」。如果你以前在笔记里写过 `- [ ] 内容` 形式的清单，它们会自动出现在「全部」里。
3. **建第一条**：点工具栏的 `+`。在 SiYuan 空间里，任务会写进你当天的日记（位置可以改，见[设置项说明](#设置项说明)）；切到「独立空间」再新建，任务只存在插件里，不进任何文档。
4. **勾掉它**：点任务左边的圆圈。笔记里那个块也会同时被勾上。
5. **换个看法**：点右上角的「树形」或「看板」，同一个任务换个角度管理。

就这样，其他功能可以按需慢慢发现。

## 两个数据空间

插件里有两套**互相独立**的数据，左侧边栏就是它们之间的开关：

| 空间 | 数据在哪 | 适合放什么 |
|---|---|---|
| **SiYuan 空间** | 你笔记里的任务列表块（`- [ ] 内容`）。插件只读写这些块，勾选、改标题都直接改笔记。 | 和笔记绑在一起的事，比如在书摘里记「回头查一下」 |
| **独立空间** | 插件自己的存储文件。**不建文档、不写块、不进全文搜索、不参与笔记同步。** | 纯任务：项目、周计划、临时清单 |

两个空间共用同一套列表 / 树形 / 看板、同一套优先级与状态，但**数据互不可见**：在 SiYuan 空间里看不到独立空间的任务，反过来也一样。

**独立空间是干净的**：在里面新建、勾选、删除任务，你的笔记一个字都不会改变。删掉插件目录之外，笔记里也找不到任何痕迹。

**切换空间会清空选中和勾选**，避免手快把一边的任务操作到另一边。

## 界面说明

```
┌──────────────┬──────────────────────────────────────────────────────┐
│ SY 待办      │  🔍 搜索…          ≡   +        [列表|树形|看板] ? ↶ ↷ ⟳│
│ 共 47 条     ├──────────────────────────────────────────────────────┤
│              │  ▾ □ P0  修正线上问题       逾期2天    工作  …/日记    │
│ 数据空间      │    ▾ □ P2  拆分复现步骤     今天                      │
│ ●SiYuan 空间 42│        □ P3  补一条回归用例 明天                      │
│ ○独立空间 5   │  □ P2  补充测试用例         今天                      │
│              │                                                      │
│  ⚙ 设置      │                                                      │
└──────────────┴──────────────────────────────────────────────────────┘
```

**左侧边栏**：只在两个数据空间之间切换（各自带任务数），底部是设置入口。时间筛选不在这里。

**顶部工具栏**

| 元素 | 作用 |
|---|---|
| 搜索框 | 边打边筛，匹配标题、备注、分类、文档路径 |
| `≡` | 展开筛选与排布：状态、优先级、截止、分类、分组、排序 |
| `+` | 新建任务 |
| `列表 / 树形 / 看板`（右上角） | 切换视图形态 |
| `?` | 显示快捷键提示 |
| `↶` `↷` | 撤销 / 重做刚才的修改 |
| `⟳` | 重新读取笔记里的最新数据 |

**`≡` 里能做什么**

- **时间**：今天 / 近七天 / 全部 / 回收站，括号里是当前空间的数量。
- **状态**：待办 / 执行中 / 已完成 / 已归档，点一下就筛选，再点取消。
- **优先级**：`P0`~`P3` 任意组合。
- **截止**：不限 / 已逾期 / 今天到期 / 本周内 / 无日期。
- **分组**：不分组 / 按日期 / 按优先级 / 按分类 / 按文档。
- **排序**：手动 / 截止 / 优先级 / 创建时间 / 标题。

**一条任务长什么样**

```
▾  □  P1  写周报                       今天  ↻  2/5  ≡  #工作  …/日记/2026-10
↑  ↑   ↑   ↑                            ↑    ↑   ↑    ↑   ↑
│  │   │   └ 标题（双击可改）             │    │   │    │   └ 所属文档
│  │   │                                 │    │   │    └ 分类
│  │   │                                 │    │   └ 有备注
│  │   │                                 │    └ 重复任务
│  │   │                                 └ 截止日期
│  │   └ 优先级（点一下循环切换）
│  └ 完成（点一下勾掉）
└ 折叠箭头：仅树形视图中有子任务时出现
```

**右侧详情面板**：点任意一条任务，右边会展开详情，可以改标题、状态、优先级、日期、重复、分类，写多行备注。再点一下右上角的 ✕ 收起。

## 三种视图

右上角切换，三种视图看的是同一批任务，改了这边那边立刻同步。

### 列表

跨文档平铺所有符合筛选条件的任务，默认不分组，按当前排序方式逐条排列。适合日常刷一遍、快速勾掉。

- **不按父子关系缩进**，也不显示折叠箭头；父任务和子任务都是独立的一行。
- 分组只增加分组标题，组内仍是平铺任务；父子关系不会改变行顺序。
- 需要调整层级、折叠分支或拖拽排序，请切换到树形视图。

### 树形

只显示层级关系，最适合拆解复杂的事。

- 工具栏的 `+` 新建根任务；鼠标移到任意任务上，点右侧 `+` 新建子任务。
- 拖到一条任务**中部**：成为它的子任务；拖到一条任务的**上／下边缘**：和它交换同级顺序。
- 层级没有上限，可以一直往下拆，缩进会跟着层级自动加深。
- 点三角箭头折叠分支，`←` `→` 也能折叠 / 展开当前行。
- 父任务不满足当前筛选时，会以弱化样式保留下来当上下文，整棵树不会因此散架。

### 看板

按状态分成四列：待办 / 执行中 / 已完成 / 已归档。

- 把卡片从一列拖到另一列，任务状态就变了。
- 拖到「已完成」时，笔记里对应的块也会被勾上。
- 每张卡片上能看到优先级、截止日期、子任务进度、分类。

---

## 四种状态

| 状态 | 含义 | 在笔记里怎么体现 |
|---|---|---|
| **待办** | 还没开始 | 未勾选 |
| **执行中** | 正在做 | 未勾选（状态记在块的属性里） |
| **已完成** | 做完了 | **已勾选** |
| **已归档** | 做完了、暂时不想看到 | 未勾选（状态记在块的属性里） |

这四种状态是刻意这样设计的，为的是和思源本身的勾选行为保持一致：

- 你在笔记里直接勾掉一个任务，插件里立刻变成「已完成」；
- 在看板里拖到「已完成」，笔记里那个块也会被勾上；
- 而「执行中」「已归档」不会影响勾选，所以不会干扰你在笔记里正常阅读。

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 新建任务 | 点工具栏 `+`，填好字段后确认（`Ctrl/Cmd + Enter`） |
| 改标题 | 双击任务标题，改完回车；或选中后在右侧详情里改 |
| 完成 / 取消完成 | 点左边的圆圈 |
| 改优先级 | 点 `P0`~`P3` 标签，循环切换；或在详情面板直接点 |
| 改状态 | 看板里拖卡片，或详情面板点状态胶囊 |
| 设截止日期 | 详情面板 → 截止日期，选日期 |
| 设重复 | 详情面板 → 重复，选每天 / 每周 / 每月等 |
| 加分类 | 详情面板 → 分类，输入新名字或选已有的 |
| 写备注 | 详情面板 → 备注，直接打字，自动保存 |
| 加子任务 | 鼠标移到任务上，点右侧 `+` |
| 调整层级（仅树形） | 选中后按 `Tab` 缩进成上一条的子任务，`Shift+Tab` 退回去；也可以拖到另一条任务中部 |
| 调整顺序（仅树形） | 拖到另一条任务的上／下边缘，同级顺序会写回笔记 |
| 多选 | `Ctrl`（Mac 上是 `Cmd`）+ 点击 |
| 批量完成 / 删除 | 多选后按 `空格` / `Delete` |
| 删除 | 点任务右侧的垃圾桶，或选中后按 `Delete` |
| 找回删除的 | 时间切到「回收站」，在详情里点「恢复」 |
| 彻底删掉 | 回收站里点「永久删除」，或点右上角「清空回收站」 |
| 跳到原笔记 | 点任务右侧的跳转按钮 |
| 撤销刚才的修改 | `Ctrl+Z`；重做是 `Ctrl+Shift+Z` |

**子树操作规则**：回收、恢复和永久删除父任务都会同时作用于它的全部子孙；永久删除不可撤销。折叠、缩进与拖拽排序只在树形视图可用，且拖拽需要「手动」排序。

**删除确认**：移入回收站、永久删除、清空回收站，以及批量或键盘删除，都会先弹出确认框；取消后不会修改任务数据。过滤按钮使用漏斗图标。

## 任务层级怎么来的

**父子关系就是笔记里的嵌套列表**

思源里把一条任务列表项缩进，它就成了上一条的子项。插件直接读这层结构，不额外维护一棵树：

```markdown
- [ ] 上线新版本
  - [ ] 修完兼容问题
  - [ ] 补齐发布说明
- [ ] 整理本周会议记录
```

上面这段在插件里就是：`上线新版本` 有两个子任务，`整理本周会议记录` 和它同级。

**三种方式改层级**

1. 笔记里缩进（最自然，插件立刻同步）；
2. 插件的树形视图里按 `Tab` / `Shift+Tab`；
3. 树形视图里把任务拖到另一条任务中部。

**独立空间没有笔记可依赖**

它的层级完全由插件自己维护，存在插件的存档文件里。树形视图中的操作方式一样（`Tab` / `Shift+Tab`、拖拽、详情里改父任务），只是不会、也不需要碰任何块。列表始终平铺显示这些任务。

**层级没有上限**

树形视图里子任务下面可以再挂子任务，缩进会跟着层级自动加深，不会在第五层就停住。

**父任务被筛选掉时**

树形视图会把这些父任务以弱化样式保留下来当上下文，所以子任务不会突然变成根节点；列表视图不补祖先，只平铺显示当前筛选命中的任务。

**整理建议**

- 根任务建议是「项目」或「领域」，不要直接放具体动作；
- 具体动作放到叶子节点，方便逐条勾掉；
- 用优先级标出这周必须推进的分支；
- 定期把做完的分支拖到「已归档」，看板会清爽很多。

## 设置项说明

点左侧边栏底部的「设置」。

| 设置项 | 说明 |
|---|---|
| **默认进入** | 每次打开插件时默认进哪个数据空间。 |
| **SiYuan 空间 · 新建任务写入位置** | 思源空间里新建的根任务写进哪篇文档。留空 = 自动写到当天日记。子任务永远写在父任务下面。独立空间不受此项影响。 |
| **默认视图** | 每次打开默认停在「今天」还是「全部」等。 |
| **默认展示形态** | 默认用列表、树形还是看板。 |
| **默认分组** | 列表按什么分组（日期 / 优先级 / 分类 / 文档）。 |
| **默认排序** | 列表按什么排序（手动 / 截止 / 优先级 / 创建时间 / 标题）。 |
| **重复任务勾选后推进到下一次** | 开启：完成一个「每周」任务，日期自动跳到下周，任务继续存在。关闭：直接标记为已完成。 |
| **「全部」视图包含已完成 / 已归档** | 关掉后，「全部」只显示还没做完的。 |
| **减少动效** | 关闭界面过渡动画，低配机器或不喜欢动画时打开。 |
| **恢复默认设置** | 把上面所有项恢复出厂值。 |

## 我的数据存在哪里

分两种情况，取决于你在哪个数据空间。

### SiYuan 空间

**任务本身**存在你的笔记里，就是普通的任务列表块。

**优先级、状态、截止日期这些额外信息**存在块的属性里。在思源里选中那个块，点块标 → 属性，就能看到它们：

| 属性名 | 含义 |
|---|---|
| `custom-bt-p` | 优先级，`P0` 到 `P2`，没有这个属性表示 `P3` |
| `custom-bt-status` | `doing` 执行中 / `archived` 已归档 |
| `custom-bt-due` | 截止日期 |
| `custom-bt-repeat` | 重复规则 |
| `custom-bt-cat` | 分类 |
| `custom-bt-note` | 备注 |
| `custom-bt-sort` | 手动排序权重 |
| `custom-bt-trash` | 有值表示在回收站里 |

### 独立空间

**任务只存在插件的存档里**（`data/storage/petal/sytodos/` 下的插件数据文件），不写进任何文档、不产生块、不会被全文搜索索引。

0.4.0 起使用带完整校验的 v2 存档，并保留最后成功备份；0.3.0 的旧独立空间存档会自动接续读取。每次创建、修改、移动和删除都会等待真实保存成功后才显示结果。

它跟随思源的「工作空间」走，但**不会**随文档同步到别的设备——只有你明确备份插件数据时才会被带走。卸载插件会删除这部分独立数据，卸载前请先备份。

### 共同部分

**插件自己记住的东西**：两个空间的偏好设置（默认空间、默认视图、默认分组等）。

**隐私**：插件不联网、不上传、不需要登录，没有统计和遥测。你的待办不会离开你的设备。

**备份**：SiYuan 空间用思源自带的同步、快照或导出功能即可；独立空间需要备份插件的存储文件。

## 常见问题

**打开后一条待办都没有？**

先看一眼侧边栏现在停在哪个数据空间：

- **独立空间**：它一开始本来就是空的，点 `+` 建第一条即可；
- **SiYuan 空间**：插件只识别思源里的「任务列表」块。如果你以前用的是无序列表（`- 内容`）或者手打的方括号，它不是任务块。在笔记里输入 `/任务列表` 回车，或用 `[] ` 开头，就能建出真正的任务块。

**和思源自带的勾选是一回事吗？**

在 SiYuan 空间里是：插件没有另存一份数据，它显示的就是你笔记里的任务块。独立空间不是——那里的任务没有对应的块。

**独立空间的任务会写进笔记吗？**

不会。独立空间的读写全部落在插件自己的存档上：不建文档、不写块属性、不进全文搜索，也不会被思源的同步带到别的设备。

**升级后我之前在「独立空间」里建的任务去哪了？**

0.3.0 之前，独立空间的任务其实被写在了一篇叫《SY 待办 任务树》的文档里。现在它们就只是普通的笔记任务，会出现在 SiYuan 空间里；独立空间从一条空白重新开始，两边不会再混在一起。那篇文档不会被删，你可以自己决定保留还是删掉。

**卸载插件，任务会丢吗？**

SiYuan 空间的任务块不会被改动；独立空间的数据属于插件私有存储，卸载前需要单独备份。

**拖动任务时会发生什么？**

在树形视图且使用「手动」排序时，拖到一条任务的**中部**会成为对方的子任务；拖到**上／下边缘**会改变同级顺序。落点会实时高亮，层级和顺序都会真实写回笔记里的块结构。跨文档移动后，所属文档和路径也会一起更新。

**插件会不会自己新建文档？**

不会。插件只在你要新建任务时，往你指定的文档（默认当天日记）里追加任务列表块，不会另外创建任何专用文档。

**在看板里改了状态，笔记里为什么没勾选？**

拖到「已完成」会勾上；拖到「执行中」「已归档」不会改动勾选状态——这是为了不干扰你在笔记里的正常阅读。状态记在块的属性里。

**手机能用吗？**

可以。手机端装上插件后同样能打开，界面会自动适配窄屏，详情面板会变成从右侧滑出的抽屉。

**任务很多会卡吗？**

不会。列表只渲染当前屏幕能看到的几十行，剩下的滚动时才画。几千条待办也能流畅滚动。

**重复任务完成后为什么没有新生成一条？**

设计上默认是「日期推进」：完成一个每周任务，它自己跳到下一周，继续存在，而不是再复制一条。想要「完成就结束」的效果，在设置里关掉「重复任务勾选后推进到下一次」。

**能同时选中多条一起改吗？**

可以。`Ctrl`（Mac 是 `Cmd`）+ 点击多选，然后按 `空格` 全部完成、按 `Delete` 全部删除。

**支持英文吗？**

支持。界面跟随思源的语言设置，中文和英文都已内置。

**会跟随深色主题吗？**

会。插件的配色全部取自思源当前主题，切换主题、换第三方主题都会自动适配。

## 名字的由来

**SY** 有两层意思，刚好重合在了一起：

- 它是 **SiYuan**（思源）的缩写；
- 也是我们两个人名字的首字母——**S** 来自太太 Song Lijuan，**Y** 来自我的 Yi Changsheng。

**Todos** 就是「待办」的复数。

所以 SYTodos 既可以读成「思源的待办」，也可以读成「我们的待办」。一个天天要用的工具，用两个人都看得懂、都觉得亲近的名字来命名，刚刚好。
