# SY 待办

**思源笔记里的待办管理插件**｜[English](./README.md)

![界面预览](preview.png)

把散落在各个文档里的 `- [ ]` 待办收拢到一处，用列表、树形、看板三种方式管理。所有数据都是你笔记里真实存在的块，插件只是给它们换了个更好用的界面。

- **不搬家**：待办还在原来的笔记里，插件不会把数据藏进私有数据库。
- **不上传**：纯本地运行，不联网、不采集，不需要账号。
- **不丢数据**：卸载插件，笔记里一条待办都不会少。
- **不卡顿**：几千条待办照样流畅，列表只渲染你看得见的部分。

## 安装

**方式一：从集市安装**

打开思源笔记 → `设置` → `集市` → `插件` → 搜索「**SY 待办**」→ 点击安装。

**方式二：手动安装**

1. 下载插件包 `package.zip`；
2. 在思源里打开 `设置` → `集市` → `已下载` → `插件`；
3. 点右上角的手动安装按钮，选择 `package.zip`；
4. 安装完成后**重启一次思源**。

**启用**

安装后如果顶栏没有出现勾选图标，去 `设置` → `集市` → `已下载` → `插件`，确认「SY 待办」的开关是打开的。

支持 Windows、macOS、Linux、Docker，以及手机端和浏览器端；需要思源笔记 **3.0.0 或更高版本**。

## 五分钟上手

1. **打开**：点击顶栏的 ✓ 图标，或按 `Ctrl+P` 搜索「打开 SY 待办」。
2. **看已有待办**：如果你以前在笔记里写过 `- [ ] 内容` 形式的清单，它们会自动出现在「全部」里。
3. **建第一条**：在最上面的输入框敲字，按回车。任务会写进你当天的日记里（位置可以改，见[设置项说明](#设置项说明)）。
4. **勾掉它**：点任务左边的圆圈。笔记里那个块也会同时被勾上。
5. **换个看法**：点右上角的「树形」或「看板」，同一个任务换个角度管理。

就这样，其他功能可以按需慢慢发现。

## 两个空间：SiYuan 任务与独立空间

插件里有两类任务，靠左侧边栏的「数据范围」切换：

| 空间 | 是什么 | 适合放什么 |
|---|---|---|
| **SiYuan 任务** | 你在笔记里写的普通任务清单（`- [ ]`）。插件自动汇总全库的这类任务。 | 和笔记内容绑在一起的待办，比如读书笔记里的「回头查一下这个概念」 |
| **独立空间** | 一棵专门用来管事的任务树，单独存在一个文档里，和你的笔记互不打扰。 | 项目拆解、长期计划、每周清单这类纯任务内容 |
| **全部任务** | 上面两者合在一起看。 | 想一眼看全所有事的时候 |

两个空间的数据都在思源里，都支持层级、状态、优先级、截止日期、重复、分类和备注。

┌──────────┬──────────────────────────────────────────────────────────┐
│ SY 待办  │  🔍 搜索…              ≡   分组▾  排序▾   [列表|树形|看板] │
│ 共 47 条 ├──────────────────────────────────────────────────────────┤
│          │ 时间 [今天3][近七天7][全部42][回收站2] │ 状态 [待办][执行中]… │
│ 数据范围  │ ──────────────────────────────────────────────────────── │
│ ● 全部任务│  ＋ 输入待办后回车保存                            [添加]    │
│ ○ SiYuan │ ──────────────────────────────────────────────────────── │
│ ○ 独立空间│  逾期                                                     │
│          │  ▾ □ P0  修正线上问题           逾期2天                   │

**左侧边栏**：只有两件事——切换数据范围、进入设置。

**顶部工具栏**

| 元素 | 作用 |
|---|---|
| 搜索框 | 边打边筛，匹配标题、备注、分类、文档路径 |
| `≡` | 展开更多筛选条件（优先级、截止、分类） |
| 分组 / 排序 | 决定列表怎么排布 |
| `列表 / 树形 / 看板`（右上角） | 切换视图形态 |
| `?` | 显示快捷键提示 |
| `↶` `↷` | 撤销 / 重做刚才的修改 |
| `⟳` | 重新读取笔记里的最新数据 |

**搜索框下面一行**

- **时间**：今天 / 近七天 / 全部 / 回收站，括号里是数量。
- **状态**：待办 / 执行中 / 已完成 / 已归档，点一下就筛选，再点取消。

**一条任务长什么样**

```
▾  □  P1  写周报                       今天  ↻  2/5  ≡  #工作  …/日记/2026-10
↑  ↑   ↑   ↑                            ↑    ↑   ↑    ↑   ↑
│  │   │   └ 标题（双击可改）             │    │   │    │   └ 所属文档
│  │   │                                 │    │   │    └ 分类
│  │   │                                 │    │   └ 有备注
│  │   │                                 │    └ 重复任务
│  │   │                                 └ 截止日期
│  │   └ 优先级（点一下循环切换）
│  └ 完成（点一下勾掉）
└ 折叠箭头：有子任务时才出现
```

**右侧详情面板**：点任意一条任务，右边会展开详情，可以改标题、状态、优先级、日期、重复、分类，写多行备注。再点一下右上角的 ✕ 收起。

## 三种视图

右上角切换，三种视图看的是同一批任务，改了这边那边立刻同步。

### 列表

跨文档平铺所有任务，按「分组」条件分块（逾期、今天、明天、本周内、以后、无日期……）。适合日常刷一遍、快速勾掉。

- 有子任务的行前面会出现三角箭头，点一下折叠整棵子树。
- 排序切到「手动」后，可以拖动行来改顺序。

### 树形

只显示层级关系，最适合拆解复杂的事。

- 顶部有「新建根任务」输入框，回车就在树的顶层加一条。
- 拖住一条任务丢到另一条上，它就变成对方的子任务。
- 层级没有上限，可以一直往下拆。
- 点三角箭头折叠某个分支。

### 看板

按状态分成四列：待办 / 执行中 / 已完成 / 已归档。

- 把卡片从一列拖到另一列，任务状态就变了。
- 拖到「已完成」时，笔记里对应的块也会被勾上。
- 每张卡片上能看到优先级、截止日期、子任务进度、分类。

## 四种状态

| 状态 | 含义 | 在笔记里怎么体现 |
|---|---|---|
| **待办** | 还没开始 | 未勾选 |
| **执行中** | 正在做 | 未勾选（状态记在块的属性里） |
| **已完成** | 做完了 | **已勾选** |
| **已归档** | 做完了、暂时不想看到 | 未勾选（状态记在块的属性里） |

这四种状态是刻意这样设计的，为的是和思源本身的勾选行为保持一致：

- 你在笔记里直接勾掉一个任务，插件里立刻变成「已完成」；
- 在看板里拖到「已完成」，笔记里那个块也会被勾上；
- 而「执行中」「已归档」不会影响勾选，所以不会干扰你在笔记里正常阅读。

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 新建任务 | 顶部输入框打字 + 回车；可先选优先级、勾「今天」 |
| 改标题 | 双击任务标题，改完回车；或选中后在右侧详情里改 |
| 完成 / 取消完成 | 点左边的圆圈 |
| 改优先级 | 点 `P0`~`P3` 标签，循环切换；或在详情面板直接点 |
| 改状态 | 看板里拖卡片，或详情面板点状态胶囊 |
| 设截止日期 | 详情面板 → 截止日期，选日期 |
| 设重复 | 详情面板 → 重复，选每天 / 每周 / 每月等 |
| 加分类 | 详情面板 → 分类，输入新名字或选已有的 |
| 写备注 | 详情面板 → 备注，直接打字，自动保存 |
| 加子任务 | 鼠标移到任务上，点右侧 `+` |
| 调整层级 | 选中后按 `Tab` 缩进成子任务，`Shift+Tab` 退回去 |
| 调整顺序 | 排序切到「手动」后拖动 |
| 多选 | `Ctrl`（Mac 上是 `Cmd`）+ 点击 |
| 批量完成 / 删除 | 多选后按 `空格` / `Delete` |
| 删除 | 点任务右侧的垃圾桶，或选中后按 `Delete` |
| 找回删除的 | 时间切到「回收站」，在详情里点「恢复」 |
| 彻底删掉 | 回收站里点「永久删除」，或点右上角「清空回收站」 |
| 跳到原笔记 | 点任务右侧的跳转按钮 |
| 撤销刚才的修改 | `Ctrl+Z`；重做是 `Ctrl+Shift+Z` |

## 键盘快捷键

先点一下列表区域，然后：

| 按键 | 作用 |
|---|---|
| `↑` `↓` | 上一条 / 下一条 |
| `Enter` | 编辑当前任务标题 |
| `空格` | 完成 / 取消完成（多选时作用于全部选中项） |
| `Tab` | 缩进成上一条的子任务 |
| `Shift` + `Tab` | 取消缩进 |
| `N` | 跳到输入框，准备新建 |
| `Delete` | 移入回收站 |
| `Ctrl/Cmd` + `Z` | 撤销 |
| `Ctrl/Cmd` + `Shift` + `Z` | 重做 |
| `R` | 重新读取数据 |
| `Esc` | 取消编辑、清空多选 |

## 搜索与筛选

搜索框和下面的条件可以**叠加**使用，边改边出结果。

几个实际用法：

| 我想… | 怎么设 |
|---|---|
| 看今天还剩什么 | 时间选「今天」 |
| 找本周必须交的活儿 | 时间选「近七天」，状态只留「待办」「执行中」 |
| 只看拖了很久的 | 点 `≡` 展开，截止选「已逾期」，优先级勾上 `P0` |
| 找某个项目的全部待办 | 搜索框输入项目名，或在 `≡` 里填分类 |
| 清理一下 | 时间切「回收站」，确认后点「清空回收站」 |
| 看某个阶段 | 状态点「执行中」 |

不确定现在生效了哪些条件时，点 `≡` 里的「清空筛选」一键复位。

## 独立空间详解

**它会自己建一个文档**

第一次进入「独立空间」时，插件会在你的第一个笔记本里新建一篇《SY 待办 任务树》，把任务树存在里面。你也可以在设置里把它指向任意已有文档。

**为什么放在文档里**

因为这样数据是看得见、摸得着的：在思源里打开那篇文档，就能看到整棵树；思源的同步、快照、导出、全文搜索对它都生效。插件坏掉或者被你删掉，树还在。

**无限层级**

根任务下面可以挂子任务、子任务下面再挂子任务，没有层数限制。用 `Tab` 加层级，或者在树形视图里把任务拖到目标任务上。

**日常整理建议**

- 一层的根任务建议是「项目」或「领域」，不要直接放具体动作；
- 具体动作放到叶子节点，方便逐条勾掉；
- 用优先级标出这周必须推进的分支；
- 定期把做完的分支拖到「已归档」，看板会清爽很多。

## 设置项说明

点左侧边栏底部的「设置」。

| 设置项 | 说明 |
|---|---|
| **任务树所在文档** | 独立空间存哪篇文档。留空则由插件自动创建。也可以手动选一篇已有文档。 |
| **SiYuan 任务默认写入位置** | 新建任务写进哪篇文档。留空 = 自动写到当天日记。 |
| **默认时间视图** | 每次打开默认停在「今天」还是「全部」等。 |
| **默认展示形态** | 默认用列表、树形还是看板。 |
| **默认分组** | 列表按什么分组（日期 / 优先级 / 分类 / 文档）。 |
| **默认排序** | 列表按什么排序（手动 / 截止 / 优先级 / 创建时间 / 标题）。 |
| **重复任务勾选后推进到下一次** | 开启：完成一个「每周」任务，日期自动跳到下周，任务继续存在。关闭：直接标记为已完成。 |
| **「全部」视图包含已完成 / 已归档** | 关掉后，「全部」只显示还没做完的。 |
| **减少动效** | 关闭界面过渡动画，低配机器或不喜欢动画时打开。 |
| **恢复默认设置** | 把上面所有项恢复出厂值。 |

## 我的数据存在哪里

**任务本身**存在你的笔记里，就是普通的任务列表块。

**优先级、状态、截止日期这些额外信息**存在块的属性里。在思源里选中那个块，点块标 → 属性，就能看到它们：

| 属性名 | 含义 |
|---|---|
| `custom-bt-p` | 优先级，`P0` 到 `P2`，没有这个属性表示 `P3` |
| `custom-bt-status` | `doing` 执行中 / `archived` 已归档 |
| `custom-bt-due` | 截止日期 |
| `custom-bt-repeat` | 重复规则 |
| `custom-bt-cat` | 分类 |
| `custom-bt-note` | 备注 |
| `custom-bt-sort` | 手动排序权重 |
| `custom-bt-trash` | 有值表示在回收站里 |

**插件自己只记住很少的东西**：上面那些默认视图、默认分组之类的偏好设置。

**隐私**：插件不联网、不上传、不需要登录，没有统计和遥测。你的待办不会离开你的设备。

**备份**：用思源自带的同步、快照或导出功能即可，插件没有私有格式需要另外备份。

## 常见问题

**打开后一条待办都没有？**

插件只识别思源里的「任务列表」块。如果你以前用的是无序列表（`- 内容`）或者手打的方括号，它不是任务块。在笔记里输入 `/任务列表` 回车，或用 `[] ` 开头，就能建出真正的任务块。

**和思源自带的勾选是一回事吗？**

是。插件没有另存一份数据，它显示的就是你笔记里的任务块。

**卸载插件，任务会丢吗？**

不会。卸载只会删掉插件自己，笔记里的任务块一个都不会动。

**「独立空间」的任务在哪？能看到吗？**

能。详情面板底部有文档路径，点一下就能跳到那篇《SY 待办 任务树》。它是一篇普通文档，可以直接打开、编辑、导出。

**为什么拖动任务没有反应？**

排序方式需要切到「手动」才允许拖动。树形视图里拖到另一条任务上是改层级，不受这个限制。

**在看板里改了状态，笔记里为什么没勾选？**

拖到「已完成」会勾上；拖到「执行中」「已归档」不会改动勾选状态——这是为了不干扰你在笔记里的正常阅读。状态记在块的属性里。

**手机能用吗？**

可以。手机端装上插件后同样能打开，界面会自动适配窄屏，详情面板会变成从右侧滑出的抽屉。

**任务很多会卡吗？**

不会。列表只渲染当前屏幕能看到的几十行，剩下的滚动时才画。几千条待办也能流畅滚动。

**重复任务完成后为什么没有新生成一条？**

设计上默认是「日期推进」：完成一个每周任务，它自己跳到下一周，继续存在，而不是再复制一条。想要「完成就结束」的效果，在设置里关掉「重复任务勾选后推进到下一次」。

**能同时选中多条一起改吗？**

可以。`Ctrl`（Mac 是 `Cmd`）+ 点击多选，然后按 `空格` 全部完成、按 `Delete` 全部删除。

**支持英文吗？**

支持。界面跟随思源的语言设置，中文和英文都已内置。

**会跟随深色主题吗？**

会。插件的配色全部取自思源当前主题，切换主题、换第三方主题都会自动适配。
